在打開dc的config 填入


第一步：建立 Discord 頻道

1. 開啟 Discord：進入你想管理的伺服器（必須擁有「管理頻道」的權限）。
2. 新建頻道：點擊左側頻道列表旁的 「＋」號（建立頻道）。
3. 選擇類型：選擇 「文字頻道」，並輸入你想要的頻道名稱（例如：通知群組）。
4. 完成建立：點擊「建立頻道」即可。


第二步：取得 Webhook URL

Webhook URL 是外部服務（如 GitHub、程式碼）將訊息傳送到該頻道的專屬網址。
1. 進入頻道設定：滑鼠移到剛建立的頻道上，點擊右側的 「齒輪圖示」（編輯頻道）。
2. 找到整合分頁：在左側選單中點選 「整合」 (Integrations)。
3. 建立 Webhook：點擊 「Webhook」，然後選擇 「建立 Webhook」。
4. 複製網址：你可以自訂這個 Webhook 的名稱與頭像，確認發送頻道正確後，點擊 「複製 Webhook URL」 即可。


第三步：取得 Mention ID (使用者 ID)

1. 開啟 Discord 開發者模式

• 點擊 Discord 左下角的 「齒輪圖示」（使用者設定）。
• 在左側選單下滑找到 「進階」 (Advanced)。
• 將 「開發者模式」 (Developer Mode) 開啟。

2. 複製使用者 ID (User ID)

• 返回聊天畫面，找到你想獲取 ID 的使用者（或是你自己）。
• 在其頭像或名字上點擊滑鼠右鍵。
• 點選選單最下方的 「複製使用者 ID」（Copy User ID），你會得到一串純數字（例如：123456789012345678）。
